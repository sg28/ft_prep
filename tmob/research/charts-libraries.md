# Charts for Design Experience

## JavaScript Charting Libraries Comparison

| Library | First Release | Ideal Use | Rendering Tech | Strength |
|---------|--------------|-----------|----------------|----------|
| Apache ECharts | 2013 (Baidu), 2018 (Apache) | Real-time time-series, complex dashboards, 3D, heatmaps | WebGL + Canvas | Enterprise-grade, scalable |
| D3.js | 2011 | Custom, algorithmic, or topology charts | SVG + Canvas | Ultimate flexibility |
| Visx (by Airbnb) | 2020 | React + D3 hybrid for custom dashboards | SVG + React | Type-safe, composable |
| Recharts | 2016 | Business-style KPI dashboards | SVG | Easy, declarative React API |
| Plotly.js / React-Plotly | 2015 | Scientific or statistical time-series | WebGL + SVG | Analytical precision |
| Nivo | 2017 | Themed charts with animations | Canvas + SVG | Quick setup, good visuals |
| Chart.js / React-Chartjs-2 | 2013 | Lightweight metrics, small datasets | Canvas | Minimal setup |
| Deck.gl + Mapbox GL | 2016 | Geospatial coverage, heatmaps | WebGL | Telecom coverage & tower data |
| Cytoscape.js / Sigma.js | 2013 | Network topology & attack graphs | WebGL | Handles thousands of nodes |
