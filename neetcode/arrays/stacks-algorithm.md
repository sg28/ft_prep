## 1. Push

```plaintext
push(n) {
    this.stack.push(n); // Add n to the top of the stack
}
```

## 2. Pop

```plaintext
pop() {
    return this.stack.pop(); // Remove and return the top element
}
```

## 3. Peek

```plaintext
peek() {
    return this.stack[this.stack.length - 1]; // Return the top element without removing it
}
```
