Lesson — Leaky (Leaking) Bucket (Read-only, no questions)
- Mental model: FIFO queue drains at a fixed outflow rate. 
Incoming requests join the queue; if the queue is full (bucket size reached), 
new requests are dropped.
- Parameters:
  - Bucket size: maximum queued requests (memory bound).
  - Outflow rate: fixed processing rate, for example r requests/second.
- Accept/reject: Enqueue if space; else reject. Processor removes requests at a steady rate.
- Pros: smooths traffic to downstream; predictable outflow; memory bounded.
- Cons: bursts can fill the queue causing head-of-line blocking; 
        recent requests may be dropped while old ones wait; tuning size/outflow is nontrivial.
- Good fit: when a downstream must be protected by a stable rate (payments, fragile services), 
        or when smoothing spikes is required.
- Contrast with token bucket: token bucket allows short bursts up to capacity if tokens exist; 
        leaky bucket enforces a constant drain rate and may delay/drop during bursts.
- In practice: Shopify uses a leaky bucket for API rate limiting.

Real example — Checkout payments (small)
- Downstream payment processor handles 10 requests/second safely.
- Configure leaky bucket: outflow = 10 rps, bucket size = 50.
- t=0: flash sale sends 40 requests → all enqueued; they drain in ~4s at 10 rps.
- t=1s: another burst of 30 → only ~20 slots free; 20 enqueued, ~10 dropped (429/Retry-After).
- Result: downstream sees a smooth 10 rps; head-of-line blocking may delay newer requests.

When to use
- Protect fragile/expensive downstreams at a steady rate (payments, external APIs).

Watchouts
- Too-small queue → more drops during spikes.
- Too-large queue → long waits/timeouts. Return Retry-After and encourage client backoff.





// Leaky bucket: FIFO queue with fixed outflow rate.
class LeakyBucket {
  constructor({ bucketSize, itemsPerSecond, onProcess }) {
    if (!Number.isFinite(bucketSize) || bucketSize <= 0) throw new Error('bucketSize > 0');
    if (!Number.isFinite(itemsPerSecond) || itemsPerSecond <= 0) throw new Error('itemsPerSecond > 0');
    if (typeof onProcess !== 'function') throw new Error('onProcess must be a function');

    this.bucketSize = bucketSize;
    this.itemsPerSecond = itemsPerSecond;
    this.onProcess = onProcess;

    this.queue = [];
    this._timer = null;
  }

  start() {
    if (this._timer) return;
    const intervalMs = Math.max(1, Math.floor(1000 / this.itemsPerSecond));
    this._timer = setInterval(() => {
      if (this.queue.length === 0) return;
      const item = this.queue.shift();
      try { this.onProcess(item); } catch (_) {}
    }, intervalMs);
  }

  stop() {
    if (!this._timer) return;
    clearInterval(this._timer);
    this._timer = null;
  }

  allowOrReject(item) {
    if (this.queue.length < this.bucketSize) {
      this.queue.push({ item, ts: Date.now() });
      return {
        accepted: true,
        remaining: this.bucketSize - this.queue.length,
        headers: {
          'X-RateLimit-Limit': String(this.bucketSize),
          'X-RateLimit-Remaining': String(this.bucketSize - this.queue.length),
        }
      };
    }
    const retryAfterSec = Math.ceil((this.queue.length + 1) / this.itemsPerSecond);
    return {
      accepted: false,
      status: 429,
      headers: {
        'Retry-After': String(retryAfterSec),
        'X-RateLimit-Limit': String(this.bucketSize),
        'X-RateLimit-Remaining': '0',
      }
    };
  }

  size() { return this.queue.length; }
}

module.exports = { LeakyBucket };


const { LeakyBucket } = require('./leaky_bucket');

const bucket = new LeakyBucket({
  bucketSize: 5,
  itemsPerSecond: 10,
  onProcess: (req) => {
    // downstream handling
    // console.log('Processed', req.item.id);
  }
});

bucket.start();

// Burst: 6 arrivals immediately (1 should be rejected)
for (let i = 0; i < 6; i++) {
  const res = bucket.allowOrReject({ id: i });
  if (!res.accepted) console.log('Rejected', i, res.status, res.headers);
}

// Stop after a few seconds
setTimeout(() => bucket.stop(), 3000);
