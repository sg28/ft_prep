
Your goal is to implement a function that given a title search term 
and/or a tag, will return the Top 5 StackOverflow[1] unanswered questions 
with the highest view count created during the last week.

The StackExchange API v2.3 allows searches by tag and/or a specific term 
in the title using the GET /search endpoint[2]. 
The API documentation can also perform requests directly and display the response, 
for example:

https://api.stackexchange.com/docs/search#order=desc&sort=creation&tagged=go&intitle=git&filter=default&site=stackoverflow&run=true

The maximum question items count returned by the API with a single response 
is 100[3]. The solution should take into account that the search results may 
be split into multiple pages, in which case all the results should be fetched and processed.

The function returns an ordered collection of JSON-serializable objects containing:

The question ID
The question link
The creation date
The view count

function search(searchTerm, tag){
    const url = 'https://api.stackexchange.com/2.3/search?order=desc&sort=creation&tagged=go&intitle=git&site=stackoverflow';
    
    const formData = Math.floor(Date.now() / 1000) - (7 * 24 *60);
    const allQuestions = [];
    let page = 1;
    const pageSize = 100;

    //pagination
    while(true){
        let params = new URLSearchParams({
            order:'desc',
            sort:'creation',
            site:'stackoverflow',
            pageSize:pageSize,
            formData:formData
        })

        // create search criteria
        if(searchTerm){
           params.append('intitle',searchTerm) 
        }
        // for tag
        if(tag){
           params.append('tagged',tag) 
        }

        try{
            const response = await fetch(`${url}?{params.toString()}`);
            if(!response.ok){
                throw new Error('Error');
            }
            const data = await response.json();
            data.items.forEach(item =>{
                if(!item.is_answered){
                   allQuestions.push(item);
                }
            });

            // We have the top 5 or there is no more pages
            if(!data.has_more){
                break;
            }
            page++;
        }catch(error){
            throw new Error('Failed');
        }
    }
    allQuestions.sort((a, b) => b.view_count-a.view_count);
    
    const limit = Math.min(5, allQuestions.length);
    const result = allQuestions.slice(0, limit).map(item =>({
        question_id: item.question_id,
        question_link: item.question_link,
        creation_date: item.creation_date,
        view_count:item.view_count
    }));
    return result;
}
